# Calculator Requirements

A Python 3 calculator used from the Terminal, built step by step in SCCM4910.


1. Add two numbers.
2. Subtract two numbers.
3. Multiply two numbers.
4. Divide two non-zero numbers.
5. Display the result of the calculation.

Calculator must:
- Take in an input,
- Check what process must be done on the two numbers provided, 
- Perform the desired calculation,
- Display the result of the calculation.

How to run it:
- "python3 calculator.py"
- Enter the first number, operator (+ - * /), then the second number.
- The program will print "Result: " followed by the answer.
