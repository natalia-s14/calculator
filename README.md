# Calculator lab project

A command-line calculator that uses two inputted numbers and adds, subtracts,
multiplies or divides them, before displaying the result.

## How to run it

Run: python3 calculator.py
Operations: + - * / (using two numbers)

## How to test it

Run: ./check.sh
     echo $?
Expected output: 5 passed tests, followed by an exit status of 0
